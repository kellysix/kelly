Este fork en desarrollo de VIctory se basa en la rama main del proyecto original. VIctory es una capa de compatibilidad que ejecuta de forma nativa en Windows un título de Xbox Series a partir de los archivos que proporciona el usuario. Los cambios de este fork se centran en corregir el renderizado del mundo del juego para que el título sea jugable en un PC concreto.

Este repositorio no incluye ni distribuye el juego, copias del juego, archivos, código ni recursos del título. Para usar la capa de compatibilidad, necesitas tu propia copia del juego y debes proporcionar los archivos necesarios. El proyecto es independiente y carece de afiliación o respaldo por parte del desarrollador o del editor del juego.
Créditos
- VIctory, de Marvisak y sus colaboradores, es la base de este fork. De él proceden el cargador, los servicios de ejecución, el backend de Direct3D 12 y el recompilador de shaders. Tanto el proyecto original como este fork se distribuyen bajo la licencia GPL-3.0-or-later. El historial original se conserva íntegro y los cambios del fork se agrupan en un único commit. Repositorio de VIctory
- XCL, de ivall y sus colaboradores, sirvió como referencia para estudiar el comportamiento del mismo título en otra capa de compatibilidad. Las correcciones inspiradas en ese trabajo se implementaron desde cero en el código de VIctory. XCL se distribuye bajo la licencia GPL-2.0-only. Repositorio de XCL
- myokex implementó la protección de cada vista de una página de memoria en el commit c6dc4d8 de victory-amd. Su trabajo adapta la PR #115 de Spexivus, la corrección de joroyt y parte de la PR #1122 de VIctory, de tightfall. Joshua Odom aportó la corrección de las lecturas del kernel en la memoria del título en el commit 10ea38e de la misma familia de forks. Ambas aportaciones se incorporaron tal como estaban, salvo el ajuste necesario para resolver un conflicto de fusión. Repositorio de victory-amd
